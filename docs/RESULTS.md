# 实验结果记录

## 指标定义
- **EM**：预测答案与标准答案完全匹配的比例。
- **F1**：预测答案与标准答案的 token-level F1。
- **平均成功检索次数**：每条问题轨迹中成功返回非空结果的 BM25 调用平均次数。
- **平均搜索尝试次数**：模型提出的搜索动作平均次数，包含重复查询和空查询。
- **无效调用率**：格式错误、参数缺失或检索失败的工具调用比例。

### v0 阶段性结论

- 从 Base 到 LoRA，总体 EM 提升 5.454 个百分点；从 Base 到 Full SFT 提升 10.610 个百分点。
- Full SFT 在七个数据集上的 EM 均高于 Base 和 LoRA。
- Full SFT 相比 LoRA 的总体平均成功检索次数由 1.683 增至 1.815，但 HotpotQA 和 2WikiMultiHopQA 上略低于 LoRA；检索次数变化不能单独解释 EM 提升。
- 多跳难集仍是主要瓶颈：Full SFT 在 2WikiMultiHopQA 和 MuSiQue 上的 EM 分别只有 8.955% 和 7.219%。
- Teacher 的完整 v0 结果尚未回传本机，因此当前表只包含三份已严格合并、可审计的本地结果。
