# 实验结果记录

## 指标定义
- **EM**：预测答案与标准答案完全匹配的比例。
- **F1**：预测答案与标准答案的 token-level F1。
- **平均检索次数**：每条问题轨迹中成功或失败的搜索工具调用平均次数。
- **无效调用率**：格式错误、参数缺失或检索失败的工具调用比例。
